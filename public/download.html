다운로드 목록에서 파일 옆 …을 누르고 유지를 고르세요. “그래도 유지”를 한 번 더 누르면 파일이 저장됩니다.

파란 “Windows의 PC 보호” 창이 떠요

추가 정보 → 실행 순서로 누르면 설치가 이어집니다. 기관 보안 정책으로 실행 버튼이 보이지 않으면 전산 담당자에게 설치 허용을 요청하세요.

“스마트 앱 컨트롤이 막았어요”라고 나와요

Windows 11의 스마트 앱 컨트롤이 켜져 있으면 서명되지 않은 프로그램을 막습니다. 이 경우 설치 대신 웹 버전을 쓰거나, 전산 담당자와 설치 방법을 상의하세요.

받은 파일을 못 찾겠어요

파일 탐색기를 열고 왼쪽의 다운로드 폴더를 보세요. 브라우저에서 Ctrl + J를 누르면 받은 파일 목록이 바로 열립니다.

설치형과 포터블은 무엇이 다른가요?

기능은 같습니다. 설치형은 시작 메뉴·바탕화면에 등록되고 실행이 조금 더 빠릅니다. 포터블은 설치 없이 실행되며, 처음 열 때 압축을 푸느라 몇 초 더 걸립니다.

기록은 어디에 저장되나요?

이 PC의 사용자 폴더 안 Dawith Welfare Office에 암호화해 저장합니다. 서버나 계정으로 올라가지 않으므로, PC를 바꾸기 전에는 기관 백업 정책에 따라 이 폴더를 백업하세요.

새 버전은 어떻게 받나요?

이 페이지에서 최신 설치 파일을 다시 받아 덮어 설치하면 됩니다. 저장된 기록은 그대로 유지됩니다.
