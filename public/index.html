보안 경계

이 앱의 기본 처리 방식은 규칙·템플릿입니다. Ollama를 선택해도 127.0.0.1만 호출합니다. OpenRouter, OpenAI 등 클라우드 provider는 서버에서 허용하지 않습니다.

PRIVACY BOUNDARY

데이터는 어디로 가나요?

이 앱상담 원문·결과를 암호화한 로컬 SQLite에 저장이 PC
Ollama선택한 경우에도 127.0.0.1만 호출이 PC
클라우드 LLMOpenRouter·외부 API 경로를 제품에서 차단차단

현재 키는 개발용 로컬 키 파일을 사용합니다. 기관 배포 전에는 OS 키체인·TPM, 보관기간, 사용자 권한과 감사로그를 추가해야 합니다.
