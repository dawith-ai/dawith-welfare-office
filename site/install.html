설치가 막혔을 때

지금 보이는 화면을 고르세요. 대부분은 버튼 두어 번이면 넘어갑니다. 새로 나온 무료 프로그램이라 Windows가 조심스럽게 묻는 것이지, 파일이 잘못된 것은 아닙니다.

Edge에서 안 받아져요파란 경고 창스마트 앱 컨트롤받은 파일 찾기설치 창포터블로 쓰기

“일반적으로 다운로드되지 않습니다”가 떠요

Edge는 내려받은 사람이 적은 프로그램을 일단 멈춰 둡니다. 아래 순서대로 누르면 저장됩니다.

Dawith-Welfare-Office-Setup.exe…
삭제유지Microsoft에 보고
  1. 오른쪽 위 다운로드 목록에서 파일 옆 …을 누릅니다.
  2. 유지를 누릅니다.
  3. 한 번 더 묻는 창에서 자세히 표시 → 그래도 유지를 누릅니다.

Chrome에서는 다운로드 목록의 계속 또는 유지를 누르면 됩니다.

“Windows의 PC 보호”가 떠요

설치 파일을 처음 열면 파란 창이 뜰 수 있습니다. 아직 코드 서명 인증서가 없는 새 프로그램이라 나오는 안내입니다.

Windows의 PC 보호Microsoft Defender SmartScreen에서 인식할 수 없는 앱의 시작을 차단했습니다.
추가 정보
실행실행 안 함
  1. 창 안의 추가 정보를 누릅니다.
  2. 아래에 생긴 실행을 누릅니다.

기관 보안 정책 때문에 실행 버튼이 보이지 않으면 전산 담당자에게 설치 허용을 요청하세요. 그동안은 포터블도 같은 이유로 막힐 수 있습니다.

“스마트 앱 컨트롤이 차단했습니다”가 떠요

Windows 11의 스마트 앱 컨트롤이 켜져 있으면 서명되지 않은 프로그램을 실행하지 못하게 막습니다. 위의 파란 창과 달리 ‘실행’ 버튼이 없습니다.

  1. 설정 → 개인 정보 및 보안 → Windows 보안 → 앱 및 브라우저 컨트롤로 갑니다.
  2. 스마트 앱 컨트롤 설정에서 상태를 확인합니다.

스마트 앱 컨트롤을 끄는 것은 PC 전체의 보안 설정을 바꾸는 일입니다. 기관 PC라면 직접 바꾸지 말고 전산 담당자와 먼저 상의하세요.

받은 파일을 못 찾겠어요

  1. 브라우저에서 Ctrl + J를 누르면 받은 파일 목록이 열립니다. 파일 이름을 누르면 바로 실행됩니다.
  2. 또는 파일 탐색기(Windows + E)를 열고 왼쪽의 다운로드 폴더를 보세요.

파일 이름은 Dawith-Welfare-Office-버전-x64-Setup.exe입니다. 포터블은 이름 끝이 Portable.exe입니다.

설치 창에서는 무엇을 누르나요?

  1. 설치 범위: 그대로 두고 다음을 누릅니다.
  2. 설치 위치: 바꿀 필요가 없으면 그대로 두고 설치를 누릅니다.
  3. 마침을 누르면 앱이 열립니다. 다음부터는 바탕화면의 Dawith Welfare Office 아이콘으로 엽니다.

새 버전을 받을 때도 같은 방법으로 덮어 설치하면 됩니다. 저장해 둔 기록은 그대로 남습니다.

설치 없이 쓰고 싶어요 (포터블)

설치 권한이 없는 PC나 USB에 담아 쓰려면 포터블을 받으세요. 파일을 더블클릭하면 바로 실행됩니다. 처음 열 때 압축을 푸느라 몇 초 더 걸리고, 기능은 설치형과 같습니다.
