해외 서버 안내

Dawith는 앱을 위한 서버를 운영하지 않고, 앱에는 클라우드 AI 기능이 없습니다. 해외 서버와 연결되는 경우는 작성한 내용이 담기지 않는 아래의 몇 가지 내려받기뿐입니다.

시행일 2026년 11월 11일 · 문서 버전 2026-11-11

1. 기본 원칙

  • Dawith는 앱을 위한 서버를 운영하지 않습니다. 앱에 입력한 내용이 Dawith로 오는 일은 없습니다.
  • 앱에는 클라우드 AI(Claude·ChatGPT·Gemini 등)로 보내는 기능이 없습니다. AI 기능은 이 PC의 로컬 AI(Ollama)로만 처리하므로, 작성한 내용은 국내외 어디로도 전송되지 않습니다.
  • 해외 서버와 연결되는 경우는 아래 2항의 내려받기뿐이며, 이때 작성한 내용은 담기지 않습니다.

2. 앱이 인터넷에 연결하는 경우

아래 연결에는 작성한 내용이 담기지 않습니다. 다만 인터넷 연결의 특성상 상대 서버에 IP 주소와 기기·브라우저 정보 같은 일반적인 접속 정보가 전달됩니다.

연결상대 · 나라언제막으면
업데이트 확인·내려받기GitHub(GitHub Releases) · 미국앱을 열 때와 ‘업데이트 확인’을 누를 때 최신 버전 정보를 읽고, 업데이트를 고르면 설치 파일을 받습니다.확인만 실패하고 앱은 그대로 작동합니다.
로컬 AI 모델 내려받기Ollama 모델 저장소 · 미국‘로컬 AI 설정’에서 모델 준비를 누르면, 사용자가 설치한 Ollama 프로그램이 Ollama 모델 저장소에서 모델 파일을 받습니다.로컬 AI 모델을 쓸 수 없습니다. 규칙 기반 기능은 그대로 작동합니다.
안내 링크각 사이트사용자가 Ollama 설치 안내 같은 링크를 누를 때만 브라우저로 열립니다.-

웹 버전에서 한글 양식 엔진 파일을 찾지 못할 때만 GitHub에서 같은 엔진 파일을 받습니다. 양식 파일 내용은 보내지 않습니다. 설치형 앱에는 엔진이 들어 있습니다.

3. 제품 소개 사이트

  • 소개 사이트의 글꼴(Pretendard)은 jsDelivr CDN에서 받습니다. 이때 jsDelivr 서버에 일반적인 접속 정보가 전달됩니다.
  • 소개 사이트는 호스팅 서비스로 제공되며, 접속하면 호스팅 서비스에 일반적인 접속 정보가 전달됩니다. 설치 파일은 GitHub Releases에서 내려받습니다.
  • Dawith는 이 접속 정보를 따로 모으거나 받지 않습니다. 자세한 내용은 광고·쿠키 안내에 있습니다.

4. 이전 버전(0.9.9 이하)을 쓰신 경우

  • 0.9.9 이하 버전에는 사용자가 직접 연결하는 클라우드 AI 기능이 있었습니다. 이 버전부터 그 기능을 없앴고, 앱 데이터베이스에 남아 있던 연결 정보(로그인 토큰, API 키)는 처음 실행할 때 지웁니다.
  • 이전 버전에서 클라우드 AI 회사로 이미 보낸 내용은 Dawith가 지울 수 없습니다. 해당 회사의 정책과 삭제 절차를 이용해 주세요.
