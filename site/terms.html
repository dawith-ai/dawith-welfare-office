1. 어떤 프로그램인가요

Dawith 복지 업무 도구함(이하 ‘앱’)은 사회복지 현장의 PDF·한글 양식·이미지·텍스트·계산·기록 업무를 PC 안에서 처리하는 무료 프로그램입니다. 계정이 필요 없고, Dawith가 운영하는 서버에 연결하지 않습니다. 소스 코드는 Apache License 2.0으로 공개되어 있습니다.

2. 무료이며, 있는 그대로 제공합니다

  • 앱은 무료로 제공하며, 사용료나 광고가 없습니다.
  • 앱은 있는 그대로 제공합니다. 법령이 허용하는 범위에서, 특정 목적에 맞는지·오류가 없는지·중단 없이 작동하는지를 따로 보증하지 않습니다.
  • 법령이 허용하는 범위에서, 앱 사용으로 생긴 손해에 대해 Dawith는 책임을 지지 않습니다. 다만 Dawith의 고의 또는 중대한 과실로 생긴 손해처럼 법령상 책임을 면할 수 없는 경우는 예외입니다.
  • 중요한 기록은 기관의 백업 정책에 따라 따로 보관해 주세요. PC 고장이나 계정 삭제로 이 PC의 데이터를 잃으면 되살릴 수 없습니다.

3. AI 결과는 검토용 초안입니다

  • 로컬 AI나 외부 AI가 만든 요약·문장·초안은 담당자가 검토하기 위한 초안입니다. 사실과 다르거나 빠진 내용이 있을 수 있습니다.
  • 공식 기록, 사례 판단, 서비스 결정은 담당자가 원문과 대조해 확인하고 확정합니다. AI 결과를 확인 없이 공식 문서로 쓰지 마세요.
  • 규칙 기반 도구(개인정보 가리기, 계산기 등)의 결과도 제출 전에 한 번 더 확인해 주세요. 예를 들어 개인정보 가리기는 모든 형태의 개인정보를 찾아낸다고 보장하지 않습니다.

4. 기관의 개인정보 지침을 지켜 주세요

  • 복지 서비스 이용자의 개인정보를 다룰 때는 소속 기관의 개인정보 처리 지침, 보관 기간, 보안 규정을 따릅니다.
  • 외부(클라우드) AI는 사용자가 직접 연결하고 보낼 때마다 확인하는 선택 기능입니다. 이용자 정보를 외부 AI로 보내기 전에 기관의 승인과 필요한 동의가 있는지 확인하는 것은 앱을 쓰는 기관과 담당자의 책임입니다.
  • 외부 AI를 쓰는 동안에는 그 회사의 이용약관과 개인정보 정책도 함께 적용됩니다. 각 회사의 계정·구독·요금은 사용자와 그 회사 사이의 일입니다.
  • 기관 내부망 모드로 여러 직원이 함께 쓸 때는 계정·권한·백업을 기관이 관리합니다.

  • 실제 이용자 개인정보를 문의 메일, GitHub 이슈, 스크린샷 등 공개된 곳에 올리는 일

6. 오픈소스와 다른 회사의 프로그램

앱은 pdf-lib(MIT), rhwp(MIT) 등 오픈소스를 포함하며, 각 라이선스 고지는 설치 폴더와 저장소에 있습니다. Ollama, Claude Code, Codex, Gemini CLI 같은 외부 프로그램은 사용자가 직접 설치하며 각 프로그램의 약관을 따릅니다.
