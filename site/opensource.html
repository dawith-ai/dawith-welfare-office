오픈소스와 참고 자료

Dawith 복지 업무 도구함은 소스를 공개한 프로그램(Apache-2.0)입니다. 어떤 오픈소스를 담았고, 무엇을 참고해 만들었는지 한곳에 모았습니다.

프로그램에 담긴 오픈소스

설치 파일 안에 들어 있는 것들입니다. 라이선스 전문은 설치 폴더의 THIRD_PARTY_NOTICES.txt에 있습니다.

Node.js
Windows·Linux용에서 내 PC 안의 로컬 서버를 돌리는 실행 환경 · MIT
Electron
Mac용 앱 창과 실행 환경 (Chromium 포함, 각 구성 요소 라이선스 따름) · MIT
rhwp
HWP·HWPX 문서를 읽고 {{표식}}을 바꾸는 한글 엔진 · MIT
pdf-lib
PDF 합치기·나누기 (안에 pako, tslib, @pdf-lib/standard-fonts, @pdf-lib/upng 포함) · MIT · Zlib · 0BSD
docx
Word(.docx) 저장과 기관 양식 채우기 (안에 fflate, nanoid 등 포함) · MIT
JSZip
HWPX·DOCX 파일 풀기·묶기 (MIT·GPLv3 이중 라이선스 중 MIT로 사용, 하위 패키지 MIT·ISC) · MIT
NSIS
Windows 설치 프로그램·포터블 실행 파일 · zlib/libpng

PC에 있는 것을 빌려 씁니다

프로그램에 넣지 않고, 이미 설치된 것을 그대로 씁니다.

Microsoft Edge
Windows에서 앱 창을 여는 브라우저 · Microsoft 라이선스
Chrome · Chromium
Linux에서 앱 창을 여는 브라우저 (없으면 기본 브라우저) · BSD 등
Ollama
로컬 AI를 고를 때 PC 안에서 모델을 실행 (사용자가 따로 설치) · MIT
AI 모델
Qwen 등 Ollama로 받는 모델은 모델마다 라이선스가 다르니 모델 페이지를 확인하세요 · 모델별 상이

사이트와 개발에 쓴 도구

프로그램에는 들어가지 않습니다.

Playwright
자동 테스트와 기능 소개 화면 녹화 · Apache-2.0
gifenc

impeccable
사이트와 앱 화면의 디자인 점검 · Apache-2.0

참고한 프로젝트와 자료

코드는 가져오지 않고 구성·흐름·설계를 참고했습니다.

  • 이음오피스 소개 사이트의 구성, 운영체제별 내려받기, 오픈소스 고지 방식을 참고했습니다.
  • Orca (MIT) 기능별 GIF와 설명을 배치한 README 구성을 참고했습니다.
  • minutes (MIT) · LocalScribe · meetmind 회의록 정리 화면과 흐름을 참고했습니다.
  • Dawith 복지 허브 같은 제작자의 웹 도구 모음입니다. 현장 도구 구성, 문의 게시판, 시그니처를 이어받았습니다.
  • 가계도 기호는 McGoldrick·Gerson의 가계도 표기 관례(남성 □, 여성 ○, 사망 ×, 이혼 //)를, 생태도는 Hartman(1978)의 생태도 구성(관계의 세기·방향)을 따랐습니다.
