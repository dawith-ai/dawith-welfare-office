개인정보처리방침

Dawith 복지 업무 도구함(Dawith Welfare Office)은 계정도, Dawith가 운영하는 서버도 없는 PC용 프로그램입니다. 이 문서는 앱이 어떤 정보를 어디에 저장하고, 언제 바깥으로 보내는지를 있는 그대로 적은 것입니다.

시행일 2026년 11월 10일 · 문서 버전 2026-11-10

1. 한눈에 보기

  • Dawith는 이 앱으로 이용자의 개인정보를 수집하지 않습니다. 회원가입·로그인이 없고, 앱에 입력한 내용이 Dawith에 전달되지 않습니다. Dawith는 앱을 위한 서버를 운영하지 않습니다.
  • 작성한 내용은 이 PC에 저장됩니다. 저장 위치와 보호 방식은 아래 2항에 적었습니다.
  • 바깥으로 보내는 경우는 정해져 있습니다. 사용자가 클라우드 AI를 직접 연결해 보낼 때, 그리고 업데이트 확인처럼 내용이 담기지 않는 몇 가지 내려받기뿐입니다(3항).
  • 광고, 이용 통계(분석) 도구, 추적 쿠키를 쓰지 않습니다. 개인정보를 제3자에게 제공하거나 판매하지 않고, 처리를 다른 회사에 맡기지도 않습니다.

2. 이 PC에 저장되는 정보

설치형 앱은 모든 데이터를 Windows 사용자 폴더의 %APPDATA%\Dawith Welfare Office에 저장합니다. 이 폴더는 PC마다, Windows 계정마다 따로 있습니다.

무엇을어디에보호 방식
앱 설정(기관명, 자동 삭제 기간, 음성 인식 모델 경로), 처음 설정의 동의 기록(문서 버전과 동의 시각)앱 데이터베이스(data 폴더의 SQLite 파일)값을 AES-256-GCM으로 암호화
외부 AI 연결 정보(로그인 토큰, API 키)앱 데이터베이스AES-256-GCM 암호화. 앱 화면으로도 다시 내보내지 않음
작업 기록: 언제 어떤 종류의 설정·기록·문서가 바뀌었는지앱 데이터베이스AES-256-GCM 암호화. 상담·회의 원문은 남기지 않음
기록·문서를 앱 서버에 저장하는 기능(기관 내부 서버 운영 등)을 쓰는 경우의 원문, 맥락 메모, 초안, 기관 양식 파일앱 데이터베이스내용은 AES-256-GCM 암호화. 날짜·종류 같은 관리 정보와 원문 무결성 확인용 해시값은 암호화하지 않음
기관 내부망 모드의 직원 계정: 아이디, 역할, 비밀번호 해시앱 데이터베이스비밀번호는 scrypt 해시로만 저장하고 원문은 저장하지 않음
화면에서 저장한 내용: 기관 기본정보(기관명·담당자), 내 양식, 인원 체크 명단, 상담·회의 기록 임시 저장(최근 30건), 가계도·생태도, 한글 양식에서 옮긴 텍스트, 최근 사용 도구, 동의 기록 사본앱 창의 브라우저 저장소(localStorage). 같은 폴더 안에 있습니다앱이 따로 암호화하지 않습니다. Windows 계정 보호에 따릅니다
실행 기록: 앱 시작·업데이트·오류 상태runtime.log 등 로그 파일작성한 내용은 기록하지 않음

암호화 키는 같은 data 폴더 안의 키 파일에 보관합니다. 따라서 암호화는 데이터베이스 파일만 따로 복사되거나 유출되는 경우를 막아 주지만, 이 PC의 Windows 계정에 들어올 수 있는 사람으로부터 지켜 주지는 못합니다. PC 잠금, 계정 비밀번호, 기관 보안 정책을 함께 지켜 주세요.

PDF·이미지·한글(HWP) 파일처럼 작업할 때 고른 파일은 앱 창의 메모리에서만 읽습니다. 사용자가 저장을 누르지 않는 한 남지 않으며, 결과 파일은 사용자가 고른 폴더에 내려받습니다.

3. 바깥으로 전송되는 경우

  • 로컬 AI(Ollama): 같은 PC의 127.0.0.1로만 보냅니다. PC 밖으로 나가지 않습니다.
  • 외부(클라우드) AI: 사용자가 Claude·Codex·ChatGPT·Gemini·OpenRouter 중 하나를 직접 연결하고, 외부 AI 버튼을 누르고, 보내기 전 확인창에 동의한 경우에만 그때 고른 텍스트와 작업 지시문이 해당 회사로 전송됩니다. 전송된 내용은 그 회사의 정책에 따라 처리·보관됩니다. 처음 설정의 선택 동의를 하지 않았다면 보내기 전에 한 번 더 묻습니다.
  • AI 연결 과정: 연결 버튼을 누르면 해당 회사의 로그인 화면이 열리거나(브라우저 인증), 입력한 API 키가 그 회사로 확인 요청됩니다.
  • 업데이트 확인: 앱을 열 때와 ‘업데이트 확인’을 누를 때 GitHub에서 최신 버전 정보를 읽습니다. 작성한 내용은 담기지 않습니다.
  • 내려받기: 로컬 AI 모델은 사용자가 설치한 Ollama 프로그램이 직접 받습니다. 한글 양식 엔진은 앱에 들어 있으며, 없을 때만 GitHub에서 엔진 파일을 받습니다. 어느 경우에도 파일 내용은 보내지 않습니다.

받는 회사, 나라, 보내는 항목은 해외 서버 안내에, 도구별 처리 위치는 데이터 처리 안내에 정리했습니다.

4. 보관 기간과 삭제

  • 이 PC에 저장된 정보는 사용자가 지울 때까지 남습니다. 기관 내부 서버 등에서 자동 삭제 기간을 설정해 두면, 그보다 오래된 앱 데이터베이스의 기록·문서·양식을 앱이 지웁니다(기본값: 자동 삭제 안 함).
  • 화면에서 저장한 내용은 도구에 있는 삭제·초기화 기능으로 지우거나, 아래의 ‘모두 지우기’로 한꺼번에 지울 수 있습니다.
  • 외부 AI 연결 정보는 ‘AI 보조·연결 센터’의 연결 해제로 지웁니다.
  • 모두 지우기: Windows 설정 → 앱에서 Dawith Welfare Office를 제거한 뒤, 파일 탐색기 주소창에 %APPDATA%\Dawith Welfare Office를 입력해 열리는 폴더를 삭제합니다. 앱을 제거해도 이 폴더는 자동으로 지워지지 않습니다(다시 설치할 때 기록을 잃지 않도록).
  • 외부 AI 회사로 이미 보낸 내용은 Dawith가 지울 수 없습니다. 해당 회사의 정책과 삭제 절차를 따릅니다.

5. 동의와 철회

앱을 처음 열 때 개인정보처리방침과 이용약관에 대한 필수 동의, 외부 AI 전송에 대한 선택 동의를 받습니다. 동의 기록(문서 버전, 동의 시각)은 이 PC에만 저장됩니다. 선택 동의를 하지 않아도 로컬 기능은 모두 쓸 수 있습니다.

앱 위쪽의 설정에서 언제든 동의 내용을 확인하고 철회할 수 있습니다. 필수 동의를 철회하면 다시 동의할 때까지 도구를 쓸 수 없지만, 이 PC에 저장된 기록은 지워지지 않습니다. 이 문서가 바뀌면 앱을 열 때 바뀐 내용을 다시 확인받습니다.

6. 기관에서 이용자 정보를 다룰 때

상담 내용처럼 복지 서비스 이용자의 개인정보를 이 앱에 입력하는 경우, 그 정보를 처리하는 주체는 앱을 쓰는 기관과 담당자입니다. Dawith는 그 정보를 받거나 볼 수 없습니다. 기관의 개인정보 처리 지침, 보관 기간, 외부 전송 승인 절차를 따라 주세요. 특히 이용자 정보를 외부 AI로 보내기 전에는 기관의 승인 여부를 먼저 확인해야 합니다.

7. 안전을 위한 조치

  • 앱의 로컬 서버는 이 PC 안(127.0.0.1)에서만 열리고, 다른 웹사이트가 앱의 기능을 불러 쓰지 못하도록 막습니다.
  • 앱 데이터베이스의 내용은 AES-256-GCM으로 암호화합니다(2항의 한계 참고).
  • 외부 AI로 보내기 전에는 매번 확인창을 띄웁니다.
  • 기관 내부망 모드는 로그인 없이 다른 PC에서 접속할 수 없게 되어 있습니다.

8. 제품 소개 사이트

제품 소개 사이트는 쿠키나 브라우저 저장소를 쓰지 않고, 방문 기록을 따로 모으지 않습니다. 다만 사이트를 제공하는 호스팅 서비스와 글꼴을 내려주는 jsDelivr에는 접속할 때 일반적인 접속 정보(IP 주소, 브라우저 정보)가 전달됩니다. 자세한 내용은 광고·쿠키 안내에 있습니다.
