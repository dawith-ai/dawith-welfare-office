# 영상 스튜디오 클론·확장 기록

기준일: 2026-10-28

## 입력과 증거

- 제공된 Google Drive 파일: `BokjiVideo-Setup-1.0.0.exe`
- 파일 형식: Windows NSIS 설치 파일, 1,331,647,705 bytes
- SHA-256: `e3c05413c39341691c2e09835eafd3857bde64b0114379b51d51eaf0c30e4093`
- 설치 파일을 실행하지 않고 NSIS 내부의 `app-64.7z`와 Electron `resources/app.asar`를 정적 추출했다.
- 원본 번들에서 확인된 주요 구성: React 19, `@dnd-kit` sortable, `lucide-react`, `zod`, FFmpeg/FFprobe, whisper.cpp, Silero VAD, YuNet 얼굴 검출, 로컬 음악·효과음·스티커·글꼴 자산.
- 공식 REA CLI도 실행했다. 대형 1.9MB renderer 번들은 300초 정적 분석 제한에 도달했으므로, REA의 partial observation과 수동 번들 문자열/매뉴얼 관측을 함께 사용했다. 분석 실패를 성공으로 간주하지 않는다.

## 원본에서 관측된 기능

원본 매뉴얼과 번들 문자열에서 다음 흐름을 관측했다.

`목적 선택 → 사진·영상 고르기 → 음악 → 자막·꾸미기 → 점검·저장`

- 장면 추가·삭제·순서 변경, 사진/영상 장면 길이 조정
- 장면 전환, 자막·제목·이름 자막바, 스티커·효과음
- 음악 보관함과 내 음악 파일, 출처 표기/크레딧
- 자동 자막, Windows 음성 기반 AI 목소리
- 얼굴 검출·모자이크, 동의 여부를 확인하는 저장 전 점검표
- 기관 이름·색·글꼴·로고를 새 프로젝트에 적용
- 로컬 프로젝트 저장, 누락된 파일 다시 연결, 720p/용량 안내

원본의 Windows native FFmpeg·whisper.cpp·YuNet 구현은 이 저장소에 복사하지 않았다. 라이선스와 배포 용량을 따로 검토해야 하고, 현재 클론의 기본 경계는 브라우저/기관 PC 로컬 처리다.

## 구현 범위

`public/video-studio.js`와 `public/index.html`의 영상 스튜디오는 위 기능 중 사회복지기관 결과 영상에 우선순위가 높은 기능을 로컬 브라우저로 구현한다.

- 다중 사진·영상 가져오기, 드래그 순서 변경, 앞/뒤 이동, 삭제, 2초 이상 장면 분할
- 장면 길이, 시작/끝 트림 비율, 컷/페이드 전환
- 자막·제목·자막 모양, 기관명·행사일·화면 비율(16:9/9:16/1:1)
- 프로 타임라인의 VIDEO/CAPTION/AUDIO 트랙, 실제 플레이헤드와 스크럽, 확대 배율, 클립 양끝 트림 핸들, 오디오 파형, Undo/Redo·자동 저장, Space/Delete/Alt+↑↓·S 단축키
- 장면별 시네마틱·밝게·흑백·소프트 효과, 강도 조절, 확대·위치 조절, 줌·팬 모션, 컷·페이드·와이프 전환
- 로컬 음악 파일과 음량, 끝 화면 문구
- 촬영 동의·개인정보 검토·음악 출처 확인 체크포인트
- Canvas `MediaRecorder`로 실제 `.webm` 내보내기, JSON 프로젝트 설계도 내보내기
- 저장소의 Dawith CI 모티프를 로컬 `dawith-ci.svg`로 사용하고 영상 스튜디오 헤더·브랜드 화면에 적용

## 의도적으로 남긴 한계

- 브라우저는 WebM을 직접 기록하고, 로컬 서버/Electron에서 설치된 FFmpeg를 통해 H.264/AAC MP4로 변환할 수 있다. 변환 입력은 로컬 HTTP 경계를 벗어나지 않으며, 서버는 임시 파일을 변환 직후 삭제한다. FFmpeg 배포·코덱·특허·라이선스는 기관 배포 전에 별도 검토해야 한다.
- 얼굴 자동 검출·모자이크, 자동 자막, AI 목소리, 효과음 보관함, HWP/PDF 양식처럼 원본의 native 기능을 브라우저 클론에서 성공했다고 주장하지 않는다. 현재는 개인정보 검토 체크포인트와 기존 로컬 whisper 작업대가 안전한 대체 경계다.
- 실제 사용자가 제공한 파일은 세션 메모리에만 유지되며, 브라우저 새로고침 후 바이너리 미디어를 자동 복원하지 않는다. JSON 설계도는 미디어 파일이 아닌 편집 계약만 보존한다.

## 오픈소스 사용 경계

REA는 원본을 관찰·감사하는 개발 도구로만 사용한다. 결과물 런타임에는 REA를 포함하지 않는다. Canvas/MediaRecorder는 브라우저 표준 API이고, 기존 Welfare Office의 `docx`, `jszip`, 로컬 whisper.cpp 계약과 충돌하지 않는다. 원본 패키지의 React·FFmpeg·모델·음악·스티커 자산은 라이선스/배포 검토 없이 복사하지 않았다.
